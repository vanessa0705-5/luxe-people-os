# Harmony HR Suite

Quero desenvolver um sistema web completo de Gestão de Recursos Humanos para uso interno da empresa.

O sistema deverá possuir uma interface moderna, profissional e responsiva, utilizando as cores preto, dourado e branco.

Crie a estrutura inicial do sistema contendo:

• Tela de Login.

• Dashboard inicial.

• Menu lateral retrátil.

• Sistema de autenticação.

• Controle de usuários.

Perfis de acesso:

- Administrador Principal

- RH

- Gestor

- Consulta

Somente o Administrador Principal poderá excluir registros.

Crie a estrutura do banco de dados pensando em um sistema escalável.

O menu lateral deverá conter:

🏠 Dashboard

👥 Colaboradores

🏢 Empresas (CNPJs)

🏭 Tomadores

👨‍💼 Coordenadores

📂 Documentos

🌴 Férias

🔄 Movimentações

❌ Desligados

📊 Relatórios

⚙️ Administração

📝 Auditoria

Cada tela deverá possuir estrutura pronta para expansão futura.

Não implemente funcionalidades ainda.

Crie apenas a estrutura profissional do sistema.
